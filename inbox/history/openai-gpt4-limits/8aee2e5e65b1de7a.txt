How can I access GPT-4o and GPT-4.1 mini?
Learn about the GPT-4o models available in ChatGPT
Updated: 23 days ago
What is a model?
A model refers to a version of an AI system, each with its own capabilities, behavior, and strengths depending on how it was trained.
What is GPT-4o?
GPT-4o is a highly capable model that can interface with multiple modalities such as text, image, and audio input. GPT-4o is available to Free, Plus, Pro, Team, and Enterprise plans.
What is GPT-4.1 mini?
GPT-4.1 mini is a fast, capable, and efficient small model and excels in instruction-following, coding, and overall intelligence. GPT-4.1 mini is available in the model picker under "more models" for paid users, and will serve as the fallback model for free users once they reach their GPT-4o usage limits.
Which model should I use?
Choosing a model depends on your use case. Here is a brief overview of the differences between GPT-4o and GPT-4.1 mini:
• GPT-4o
• Great model for most tasks.
• 128k token context length.
• Text and image input/output.*
• Audio input/output.**
• GPT-4.1 mini
• Faster for everyday tasks.
• 128k token context length.
• Text and image input/output.*
• Audio input/output.**
• Does not have access to advanced tools that GPT-4o has (data analysis, file uploads, vision)
* Read this article for more information about image generation.
** Read this article for more information about voice mode.
ChatGPT Free plan
• GPT‑4o: Limited access based on overall ChatGPT demand.
• GPT‑4.1‑mini: Unlimited access.
Free plan users can use GPT-4o a limited number of times within a five hour window. ChatGPT will inform you once you’ve reached the message limit but you can continue your conversation using GPT-4.1 mini or by upgrading to Plus or Pro plans.
Free users receive limited access to messages using advanced tools through GPT-4o, such as:
• Data analysis
• File uploads
• Search
• Vision
• Deep research
Free users can upgrade to Plus or Pro at any time by visiting our pricing page .

API Support
